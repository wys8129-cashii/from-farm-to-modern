# 工业生产设备百科全书

> 一个农业社会要成长为高度现代化社会，需要哪些工业生产能力？

本项目以可视化网页的形式，系统梳理了从农业社会到现代化社会所需的六层工业生产能力栈，覆盖 160+ 关键设备名称，支持点击查看设备详情（供应商、生产流程、零部件、参考视频），并提供 JSON 数据导出/导入闭环，配合 AI 一键补充设备信息。

## 功能特性

- **六层工业能力栈** — L1 资源采掘 → L2 基础材料 → L3 动力与机床 → L4 装备制造 → L5 电子信息 → L6 现代化社会
- **160+ 设备分类** — 按子类别分组，覆盖矿业、冶金、化工、机床、交通、农业、能源、半导体等领域
- **一键复制** — 点击设备左侧图标按钮即可复制设备名称到剪贴板
- **设备详情面板** — 从右侧滑入，包含：
  - 中国主要供应商（排名、特色、市场份额）
  - 生产流程时间线（10 步工艺）
  - 零部件与关键技术（按系统分组，可复制）
  - 参考视频卡片（封面图 + 标题 + 来源链接）
- **JSON 数据导出/导入** — 闭环数据工作流：
  1. 导出 JSON 基线数据
  2. 复制 AI 提示词
  3. 把提示词 + JSON 发给 AI
  4. AI 按格式补充缺失设备详情
  5. 点击"切换数据库"导入完善后的 JSON
  6. 页面即时同步所有新数据
- **Markdown 导出** — 生成结构化 .md 文档，标记已填/待补充状态
- **数据状态指示器** — 实时显示当前数据来源（默认/已加载外部/错误）

## 技术栈

- **纯前端** — 零后端依赖，零 npm 包，单个 HTML 文件
- **HTML + CSS + Vanilla JS** — 无框架、无构建工具
- **CSS 变量设计系统** — 统一的颜色、字体、间距 token
- **FileReader API** — 本地 JSON 文件读取与解析
- **Clipboard API** — 一键复制功能
- **自包含** — 可离线运行，双击 HTML 即可打开

## 使用方式

### 直接使用

1. 下载 `industrial-equipment-encyclopedia.html`
2. 用浏览器打开
3. 左侧导航切换工业层级
4. 点击设备名称查看详情
5. 点击设备左侧图标复制名称

### AI 协作填充数据

1. 点击侧边栏 **"导出 JSON"** 下载基线数据
2. 点击 **"AI 补充提示词"** 按钮
3. 点击 **"一键复制提示词"**
4. 将提示词 + JSON 文件发给 AI
5. AI 返回完善后的 JSON
6. 点击 **"切换数据库"** 选择新 JSON 文件
7. 页面即时同步所有设备详情

## 工业能力栈说明

| 层级 | 名称 | 核心能力 | 设备示例 |
|---|---|---|---|
| L1 | 资源采掘 | 把自然资源从地里挖出来 | 挖掘机、盾构机、石油钻机 |
| L2 | 基础材料 | 把矿石变成可用材料 | 高炉、转炉、回转窑 |
| L3 | 动力与机床 | 制造机器的机器（关键转折层） | 蒸汽轮机、五轴加工中心、液压机 |
| L4 | 装备制造 | 用机器造产品 | 铁路机车、联合收割机、CT 机 |
| L5 | 电子信息 | 数字化跃迁 | 光刻机、CPU、5G 基站 |
| L6 | 现代化社会 | 工业化成果 | 光伏组件、高铁系统、手术机器人 |

> L3（动力与机床）是关键转折层——一个国家只有掌握"制造机器的机器"，才能自主复制和升级整个工业体系。

## 贡献指南

1. 导出 JSON 文件
2. 按模板格式补充设备详情
3. 提交 Pull Request，附上完善后的 JSON

### 详情填写规范

- **供应商**：至少 3-5 家中国企业，含真实市场份额数据
- **生产流程**：6-10 步，每步含简要说明
- **零部件**：4-6 个系统分组，每组 5-8 个零部件
- **参考视频**：2-4 个，使用真实可访问的 URL
